# Milo 原创场景素材

这些素材由内置 `image_gen.imagegen` 生成，用于 Buddy.ai 布局参考下的 Milo 首页和学习地图；未使用外部 API、CLI 或 API 密钥。参考的是页面的角色与入口关系，角色、火箭及房间为本项目新生成的独立素材。

| 文件 | 实际尺寸 | 背景 | 用途 |
| --- | --- | --- | --- |
| `milo-companion.png` | 1254×1254 | 透明 | 首页中央角色、地图左侧伙伴 |
| `home-room.png` | 1536×1024 | 不透明 | 首页 3:2 极简房间背景 |
| `rocket-map.png` | 1254×1254 | 透明 | 首页右下角学习地图入口 |

完整原始 prompt、来源文件、生成选项、尺寸、字节数和 SHA-256 记录在 `assets-manifest.json`。生成后已打开检查全身构图、边缘留白、背景复杂度和配色；PNG 透明通道由 macOS `sips` 验证。未裁剪、重绘或覆写生成源文件。

Milo 是方形透明画布中的纵向人物。角色槽应优先按高度确定图像尺寸，允许透明边缘延展，避免仅按窄槽宽度把人物缩得过小。不要把该图片当作绘制在按钮上的普通24px图标。

背景中央留有大圆窗及空地。角色、气泡、开心值和导航应作为独立交互层叠加；文字和按钮没有烘焙进背景图片。
