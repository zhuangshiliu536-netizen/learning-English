# Milo 首页、主 Tab 与完整单元地图验收

版本：0.4.8 · 2026-11-03  
final result: passed

## 对照目标与范围

目标为用户提供的Buddy.ai首页与路径实机截图，以及本轮明确改动：首页中央Milo、小型对话快速入口、右下火箭、左侧伙伴/右侧横向完整单元六边形、角色开心值、iOS悬浮层与儿童配色。

原参考为2556×1179；本产品沿用既定2400×1600的3:2画布。预览iframe保持2400×1600，内部舞台约2230×1487；内容截图按实际查看倍率捕获，未将两种长宽比强行拉伸到同一比例。本次是指定空间关系与产品行为的适配，不声称复刻Buddy角色、美术、金币、商业入口或原生Liquid Glass。

## 已关闭的发现与修复

1. **P2：地图伙伴过小。** 首轮角色只占左栏较小区域，与参考的伙伴主导关系不符。扩大角色图至左栏160%宽、高29rem，保留原图比例；最终图已复核角色、提示与地图分区。
2. **P2：初始定位裁掉已完成单元。** 首轮自动对齐第二单元，第一块只剩边缘。前两个单元阶段从起始位置显示，完整展示已完成、当前与后续的连续关系；最终地图已复核。
3. **P2：家长跨单元切换可能返回错误活动。** 查看另一个单元的反馈后，原活动路由可能被用于新单元。现明确回首页。已实际验证“野餐理解活动→家长→尚未开始的早餐反馈→返回孩子”，结果为首页的早餐开始气泡，未跳过阅读门槛。
4. **P2：小字对比不足。** 加深气泡辅助文字、单元编号与状态、导航辅助文字；未来节点保留图标的弱化，但不整体降低文本不透明度。最终细节图复核。
5. **P2：旧配音指向已移除按钮。** 更新野餐/早餐首页对应的中文引导音频与manifest，明确引导点击对话气泡；新声与旧版回退文字保持一致。

## 五项视觉表面检查

- **字体与文字：** 系统圆润/苹方字体栈，中文主邀请清楚，英文单元名为辅助；未沿用参考的游戏手写字形，这是iOS风格的有意选择。气泡只保留一条邀请和一个开始/继续动作。
- **布局与间距：** 首页中央角色、头部斜上方气泡、顶部心形状态、底部导航、右下火箭均稳定锚定；地图左约25%伙伴区，右侧完整单元路径可横滑。390px下气泡、开心值与导航没有互相遮挡。
- **色彩与浮层：** 使用奶油背景、雾紫地图、薄荷选中态和暖色爱心；高不透明度气泡与轻玻璃控件区别明确。整体降低场景细节，与用户此前提出的聚焦需求一致。
- **图像质量：** 原创Milo与火箭有透明通道，图像未拉伸；房间为3:2低细节生成图。未用代码绘制角色或火箭。六边形是用户指定的交互容器，使用CSS几何；图标来自官方Tabler资产。
- **内容与状态：** 每个六边形为完整单元，四个活动在单元详情中展开；前两单元实际可学，后四块明确筹备中。完成后可以重读；开心值不作为能力评估。

## 浏览器交互验证

- 首次设置→认识Milo→首页→完整野餐主线→完成，开心值20→40。
- 完成野餐后首页气泡提供真实的早餐新单元；早餐四页、三请求、表达选择与旅行页完整通过，40→60；刷新仍为60。
- 早餐中途回家→重读野餐→回家→继续早餐，恢复到早餐原来的第2页，爱心不重复增加。
- 请求使用提示后仍获得相同的2心；只选择、不录音也能完成表达并获得3心。
- 地图鼠标拖动实际滚动至后续节点；筹备单元显示明确说明；第二单元尚未解锁时显示继续前一单元入口。
- 顶部开心值在首页、地图及学习活动间保持；旧档案迁移后刷新两次仍为40，未重复补奖。
- 390×844普通视口下地图和首页无横向溢出；地图内部仍可横滑，顶部返回和家长入口可用。
- 缩放调试窗口继续保持固定画布与等比显示，50%细节检查、自动适应和恢复可用。

## 0.4.8 主 Tab 一致性修复与验证

用户反馈书架和旅行册仍沿用旧版页面，切换时框架与导航跳变。本次将书架、今天、旅行册接入同一 `world-shell`，统一顶部开心值与工具、底部导航和中间内容的留白；书架、旅行册改用奶油/浅紫背景、高不透明度圆角卡片与原创 Milo。

已关闭的发现：

1. **P2：主 Tab 使用两套页头和导航。** 三页共用顶部与底部控件，固定顺序为书架、今天、旅行册；切换仅替换中间内容，保留顶部与导航 DOM，选中样式和 `aria-current` 同步更新。
2. **P2：读故事后返回错误 Tab。** 记录来源主 Tab，从书架进入返回书架，从旅行册进入返回旅行册；未完成的故事保留上次阅读页，已完成的故事可以从第一页重读。
3. **P2：旅行册空状态主按钮文字被继承色覆盖。** 明确深紫主按钮使用白字；纯色 `#FFFFFF` / `#6554C0` 的对比度约为 5.86:1，浏览器中已确认生效。

实际检查结果：

- 2400×1600 画布中，书架、今天、旅行册的导航矩形均为 `x=843.17, y=1396.59, width=713.66, height=129.34` CSS px；三页位置与尺寸一致，当前页标签正确选中。
- 390×844 普通视口中，书架滚至 `scrollTop=272.5` 后，切到今天再返回，以及切换声音，均保留 `272.5`；无页面横向溢出。
- 窄屏内容滚动区底部约为 `726.2`，导航顶部约为 `743.8` CSS px，内容未被导航覆盖。
- 旅行册在没有完成记录时显示第一张旅行页的邀请；有真实单元完成记录时显示共同作品、孩子选择、重读与家长回顾。两种状态共用顶部和导航布局。
- 从旅行册重读后返回旅行册；从书架阅读后返回书架；早餐未完成时，再次进入恢复到第2页。Tab 切换不增加爱心。
- 320×740 下无横向溢出；旅行册空状态可在内容区内滚动到开始按钮，进入阅读后仍返回旅行册。声音提示底部为 `624`，导航顶部约为 `639.8` CSS px，没有遮挡导航。
- [书架最终预览](milo-library-preview.jpg)、[旅行册最终预览](milo-album-preview.jpg) 已由实际浏览器捕获。测试使用独立 QA 档案，未重置使用者的普通体验记录。

上述为界面和恢复行为验证，没有新增儿童可用性或学习效果结论。
