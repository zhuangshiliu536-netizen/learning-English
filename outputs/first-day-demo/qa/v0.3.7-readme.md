# Milo · 首日学习流程体验版

版本：0.3.7，2026-11-02。低保真、可交互、本地运行；角色与界面不是最终视觉设计。

## 直接体验

当前预览：[打开 Demo](http://127.0.0.1:4173/)。

等比查看：[打开缩放调试预览](http://127.0.0.1:4173/preview.html)，或点击普通 Demo 顶部的“缩放调试”。固定 2400×1600 画布，支持 1%–200% 滑杆、百分比输入、25%／50%／75%／100% 档位、每档 1.25 倍加减和“适应窗口”。缩放设置单独保存，不重置学习进度；右上角可返回正常体验。

如果预览服务已经关闭，在本目录运行 `python3 serve.py --open`。macOS 也可以双击 `启动体验.command`。需要本机 Python 3，不需要安装前端依赖。请通过本地服务打开，不要直接双击 index.html。

## 可以体验的完整路径

家长快速设置 → 认识伙伴 → 今天与学习路径 → 四页听读 → 装篮子 → 表达选择 → 共同旅行页 → 首日收尾 → 家长本次反馈。

- 年龄 3–8 岁分别配置操作密度，语言起点独立选择。
- 点击或拖动、重听、提示、减少选项、示范均可实际操作。
- 可以暂停、返回和刷新；当前浏览器保留进度。
- 点选即可完成表达活动；愿意时可尝试本地录音和回放。
- 家长反馈根据实际选择、帮助、重听和参与记录生成。
- 家长侧可查看权益与导师预约意向的演示流程。
- 顶部“重新体验”只重置这个 Demo 的本机记录。

## 本轮调整

- 以 2400×1600（3:2）为主力尺寸，按视口同步调整舞台、字号、按钮和间距。高像素密度屏幕的 1200×800 逻辑窗口同样保持 3:2 布局。
- 桌面听读、装篮子和表达选择的主要操作在首屏可见；表达页采用左右分区。长家长反馈在内容区滚动，导航留在舞台底部。
- 33 条中文引导换为晓晓神经女声，语速 -8%，音高不变。首次设置的“选择声音”或家长中心的“试听与调整声音”可对比原版。
- 新音频已随文件打包，本地播放；正常体验不调用在线语音服务。
- 新增独立缩放调试预览。改变比例时保留画布排版，不重新加载学习页面；超出窗口时可双向滚动，自动适应模式会跟随窗口尺寸变化。

## 已实现与未接入

英文伴读沿用本地系统语音音频；新增 33 条中文 MP3，原有 61 条 WAV 保留作对比与回退。新中文声音通过 edge-tts 生成，来源、音色、时长与校验信息见 `assets/audio-neural/`。图标采用 MIT 许可的 Tabler Icons。没有外部字体、运行时 CDN 或前端包安装要求。

录音需要使用者主动开启麦克风，音频仅在当前页面内存回放，不上传；刷新后录音回放失效，但可以保留录音尝试记录。没有接入语音识别、大语言模型、发音评分、正式登录、跨设备同步、真实支付、真人教室或真实预约。

首日只报告具体活动表现，不产生虚构的能力提升、等级或掌握结论。点选不等于口语，录音尝试也不等于已经识别或评价表达。

## 验证

完整点选主线、拖动、选错与帮助、正确回应后刷新、暂停恢复、完成后重玩、家长证据、权益与预约演示已在浏览器操作检查；窄屏布局检查无横向溢出，浏览器未观察到控制台错误。

2400×1600 与 1200×800 的 3:2 逻辑视口及 390px 窄屏已检查；新语音播放、对比、Esc 停止及主力尺寸拖动操作已实际验证。语音取消与回退的 9 个回归场景通过。

18 个年龄／语言配置、61 个有效 WAV、33 个有效中文 MP3、33 个 SVG 和证据计算检查通过。真实麦克风录制没有在自动检查中开启；该可选功能仍取决于用户浏览器与权限。未进行真实儿童可用性测试或学习成效验证。

## 文件

- `app.js`：页面、交互、状态保存与本地录音。
- `content.js`：原创样板故事、分级请求和音频脚本。
- `evidence.js`：基于事实记录生成家长反馈。
- `styles.css`：简洁响应式界面。
- `preview.html`、`preview.js`、`preview.css`：2400×1600 等比缩放调试窗口。
- `assets/`：本地图标、音频、许可和来源清单。
- `design-qa.md`：本轮流程与界面验收记录。

本目录可直接作为下一轮修改的源码。内部测试使用 `?qa=1` 的独立本机存储，不影响正常体验入口。
