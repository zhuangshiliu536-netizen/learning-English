版本：0.4.8 · 2026-11-03。本地可交互产品样板。

## 直接体验

[打开等比缩放预览](http://127.0.0.1:4173/preview.html) · [打开普通体验](http://127.0.0.1:4173/)

预览固定 2400×1600（3:2）画布，支持 1%–200% 缩放、每档 1.25 倍、常用倍率及适应窗口。普通体验顶部也有“缩放调试”入口。

服务关闭后，在本目录运行 `python3 serve.py --open`；macOS 可双击 `启动体验.command`。需要 Python 3，不需要安装前端包。请通过本地服务打开。

## 本轮改动

- 主 Tab：书架、今天、旅行册共用同一套顶部控件与底部悬浮导航，切换时只更新中间内容。选中状态随页面变化，导航位置、顺序和尺寸保持一致。
- 书架与旅行册：统一使用新版配色、原创 Milo、圆角内容卡和浮层样式；旅行册空状态与已有旅行页使用相同页面框架。各页保留本次会话的滚动位置；从书架或旅行册读故事后返回原 Tab，未读完的故事继续上次页。
- 首页：Milo 居中；小对话气泡开始或继续当前真实可学单元；右下角火箭进入地图；底部悬浮导航进入书架、今天和旅行册。
- 地图：左侧 Milo，右侧可横向拖动、滑动或通过箭头浏览的六边形路径。每块是一个完整单元，进入后展示听读、理解活动、表达选择和共同旅行页。
- 内容：准备野餐、早餐小帮手两个完整样板；另外四个节点明确为筹备中。完成野餐后开启早餐；全部完成后提供重读。
- 伙伴关系：初始开心值20，每单元首次完成4个故事页各+2、3个请求各+2、表达选择+3、旅行页+3，合计20心。帮助、选择而不录音不影响奖励；刷新和重玩去重，不因离开或答错减少。开心值上限100，累计爱心独立保存。
- 视觉：原创3D伙伴、简洁房间与火箭；雾紫、薄荷、奶油色；控件采用柔和悬浮层，内容保持高不透明度。
- 配音：晓晓中文女声；首页台词明确引导点击对话气泡。所有默认台词已随本地资源打包。

## 学习与家长路径

首次设置 → 认识伙伴 → 首页气泡或地图 → 四页听读 → 三个理解请求 → 表达选择（录音可选）→ 共同旅行页 → 单元收尾 → 家长事实反馈。

年龄3–8岁调整操作密度，英语起点独立配置。可点选或拖动、重听、提示、减少选项和示范；暂停和刷新可继续。两单元分别保留进度与证据，旅行册保留真实完成的共同作品。

旧版记录自动迁移到新的多单元存储；旧记录保留，新版使用独立键，避免仍打开的旧版本标签页覆盖新版记录。QA入口 `?qa=1` 始终使用独立测试档案。

家长反馈区分接触、具体回应、帮助条件和表达尝试；不把爱心、点选或录音次数当作语言能力。支付、外教意向和家长入口仍为流程演示。

## 本地资产与当前边界

现有76条WAV、57条中文神经语音MP3、35个MIT许可Tabler图标，以及3张本轮生成的原创美术图。默认台词全部有本地音频，不依赖运行时在线语音服务、CDN或外部字体。语音与美术来源、完整生成提示、时长及摘要分别见资产清单。

录音由使用者自愿开启麦克风，仅在当前窗口内存回放，不上传；刷新后回放失效。未接入语音识别、发音评分、大语言模型、正式账户、跨设备同步、真实扣费或真人教室。

## 主要文件

- `app.js`：页面、导航、互动和本地录音。
- `curriculum.js`：两个完整单元与未来节点。
- `journey.js`：单元归档、恢复及爱心去重。
- `evidence.js`：基于实际记录生成家长反馈。
- `styles.css`、`buddy.css`、`theme.css`、`collections.css`：布局、共享导航与书架/旅行册视觉。
- `preview.html`、`preview.js`、`preview.css`：等比缩放调试窗口。
- `assets/`：音频、图标、原创美术及清单。
