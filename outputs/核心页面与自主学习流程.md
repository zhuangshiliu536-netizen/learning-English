# 核心页面与自主学习流程

版本：v0.2  
日期：2026-11-02  
依据：《英语启蒙产品架构讨论稿》已确认 D01–D10。本文为页面结构和交互说明。原三版视觉草图未选定，首页信息层级正按用户反馈与海外产品调研调整；角色形象、画风及最终界面尚未确定。

## 1. 本轮落实的关键选择

- 首版同时覆盖 3–8 岁，按年龄、英语能力和操作表现适配。
- 孩子自主完成为主，产品承担说明、伴读、活动引导、帮助与衔接。
- 听说与绘本故事理解优先，系统拼读课程后续加入。
- 儿童端平板优先，手机兼容阅读和家长管理。
- 自有伙伴世界、原创样板起步，后续接入精选授权绘本。
- 伙伴围绕任务互动；大语言模型可用于重要体验与价值环节。
- 稳定外教、固定周期一对一；免费完整样板、家庭内容订阅、导师周期服务包。

自主使用不要求孩子先会读文字。首次设置和必要协助由家长承担；家长不需要日常逐步讲解才能让学习流程运行。各年龄组的实际自主程度通过儿童试用验证。

## 2. 页面关系与入口

儿童主导航暂定为“今天 / 书架 / 旅行册”。其余页面围绕当前活动进入。

| 页面或区域 | 入口 | 主要行动 | 退出或返回 |
| --- | --- | --- | --- |
| 今天：首页 | 儿童进入后的默认页 | 开始或继续当前故事任务 | 切换书架、旅行册，或自然结束 |
| 探索路径 | 首页的当前主题卡 | 查看当前活动与下一步 | 返回今天，继续当前位置 |
| 书架与绘本详情 | 儿童主导航、当前任务 | 自由选书、开始或继续听读 | 返回来源页，保存进度 |
| 绘本阅读器 | 任务或书架 | 听读、翻页、重听 | 暂停保存；读后可选相关活动 |
| 场景活动 | 当前单元节点、阅读后的邀请 | 理解、选择、动作、表达 | 求助、暂停、继续或换熟悉活动 |
| 旅行册 | 儿童主导航、活动收尾 | 回看共同作品、再次讲述 | 返回今天或相关故事 |
| 家长中心 | 经家长验证的独立入口 | 设置、证据回顾、安排、预约与购买 | 返回儿童模式 |
| 外教交流 | 已预约的老师卡片 | 进入交流、共同完成主题任务 | 生成老师观察，回到当前主题 |

儿童侧不处理会员购买、复杂日程或文字表单。需要家长安排的事项进入家长侧；孩子仍可继续访问已有内容。

## 3. 首次使用与每日使用

### 3.1 首次使用

1. 家长创建儿童档案：年龄、英语接触情况、操作与语言支持需要。
2. 家长设置使用安排、音频与语音相关权限，了解可用权益；允许不开启录音而继续可用活动。
3. 孩子认识主伙伴，直接开始一个小任务。
4. 通过任务中的语音和动作示范学会开始、选择、重听、帮助与退出。
5. 系统记录实际操作与回应，发现不合适时调整到已有的支持版本。
6. 活动结束生成旅行页与基础反馈，家长可稍后查看。

初步能力了解嵌入活动，不要求孩子完成长文字测评，也不依据年龄直接认定英语水平。

### 3.2 日常主线

**打开今天 → 伙伴接续上次经历 → 开始当前小任务 → 听读与参与 → 获得具体回应 → 留下共同结果 → 自然结束或自由重读。**

孩子可以从书架进入另一条完整听读流程。相同材料的阅读进度可同步到主线；未发生的理解或表达活动不会自动记为完成。

## 4. 首页与路径的具体结构

### 4.1 首页：一个清楚的下一步

工作草案如下，具体布局需在本轮首页结构选择后调整。所有版本都需要突出一个主要可操作对象，用语音与一致的控件样式支持儿童开始。

1. **伙伴与当前情境**：正在做什么；一句可重播的邀请。
2. **主行动**：开始或继续当前任务，按钮有语音和可识别图示。
3. **自由选择**：进入书架，或重读最近喜欢的书。
4. **共同经历**：一张最近旅行页的入口。
5. **预约提醒**：有预约时出现老师卡片，安排由家长管理。

| 首页状态 | 呈现重点 | 主行动 |
| --- | --- | --- |
| 第一次来 | 认识伙伴和一个简单任务 | 一起开始 |
| 上次中断 | 一句简短回顾、保存的位置 | 接着做 |
| 本次完成 | 刚刚共同完成的场景与旅行页 | 看看我们的旅行页；可结束 |
| 多日未使用 | 熟悉内容、欢迎回来 | 继续熟悉任务或重读 |
| 当前任务太难 | 更容易参与的活动 | 选择简单版本或换熟悉的书 |

重听、帮助与退出的位置保持可预期。不会读按钮文字的孩子也应能辨认并使用。

### 4.2 路径：看见当前位置

“准备野餐”路径示例：读故事 → 装篮子 → 表达选择 → 生成野餐旅行页。

儿童只需要理解当前任务、下一活动和可返回的位置；家长可以查看教学目标与安排原因。路径状态描述活动进度，能力状态在成长档案中另行记录。

每个节点可分次完成，语言回应困难时可以降低回应要求、增加适配支持，并记录实际提供的帮助。故事结尾不以全部答对、录音成功或购买导师服务为条件。

## 5. 一个单元如何支持不同年龄与能力

采用同一主题的不同版本，复用角色、基础素材和目标关系。年龄适配与语言难度分开配置。

| 维度 | 决定什么 | 样板做法 |
| --- | --- | --- |
| 年龄与操作表现 | 画面复杂度、操作步骤、题材表达方式 | 3–4 岁工作版本以大目标和单步示范为主；5–6、7–8 岁版本逐步提供更完整任务，均需试用 |
| 听懂程度 | 指令、可用词句和帮助程度 | 从听词找物，到理解短请求，再到情境中的问答 |
| 表达情况 | 可接受的回应与下一步邀请 | 指认、词语、短句、描述均有对应参与路径 |
| 故事理解 | 情节信息与理解活动 | 找角色、选事件、排序、讲述，根据表现选配 |

不把年长初学者放进明显低龄的题材；基础语言也可以放在适龄任务中。各组都保留语音帮助和简单操作路径。

### 5.1 野餐单元的完整体验

| 阶段 | 孩子看到或听到什么 | 孩子做什么 | 产品下一步 |
| --- | --- | --- | --- |
| 邀请 | 伙伴拿出野餐篮，邀请帮忙 | 点击开始或选择先读书 | 进入适合的听读版本 |
| 听故事 | 相关绘本及完整音频 | 听、看、翻页、暂停或重听 | 故事结束后邀请参与活动 |
| 装篮子 | 伙伴请求一件食物，有清楚的可选物品 | 点击、拖动或回应 | 对选择给出场景结果；需要时帮助 |
| 表达选择 | 伙伴询问孩子想带什么 | 指认、说词或表达想法 | 接受可确认意图，提供适配回应 |
| 一起出发 | 孩子选过的物品出现在野餐场景 | 观看结果，可再描述 | 生成共同旅行页 |
| 收尾 | 伙伴回顾具体经历 | 查看作品、结束或重读 | 保存位置，生成家长反馈 |
| 后续 | 下一次出现变化后的材料或请求 | 在新情境中再次参与 | 形成新的观察；导师方案可进一步诊断 |

### 5.2 帮助与恢复是单元的一部分

所有活动提供孩子可辨认的求助入口。帮助按教研设定的层次推进：

**重听 → 图片或动作示范 → 减少选项或拆成一步 → 示例回应 → 选择继续、换熟悉活动、暂停或找家长。**

沉默、反复尝试或未确认回应可以触发帮助邀请；产品不自行把这些情况归因为“不会英语”。语音识别不确定时可转为点击参与。恢复路径保存已完成内容，不要求整段重来。

## 6. 大语言模型首先在哪产生价值

### 6.1 第一优先：理解不同说法并给出任务内回应

在“想带什么去野餐”的情境里，孩子可能说：

| 孩子回应 | 产品可做的事 | 记录方式 |
| --- | --- | --- |
| “Apple.” | 伙伴确认选择，将苹果放进篮子 | 记录当时提问、图片支持、是否已有示范及实际表达 |
| “我要苹果。” | 理解选择，给出简短英文回应并继续任务 | 中文回应或混合语言，不能记为独立英文表达 |
| “黄色那个。” | 结合场景提出候选，让孩子确认 | 意图待确认；确认后的选择与后续表达分别记录 |
| 说出了别的想法 | 在当前故事允许范围内回应，或邀请回到可完成的选择 | 记录真实参与，不因偏离标准答案直接判错 |
| 未能确认或没有说话 | 提供可视选择、重听或示范，继续体验 | 未确认或未观察到，不判为已掌握或不会 |

候选意图只有得到足够确认后才触发对应场景动作。给过的示范、重复、选择和其他帮助都保留在证据中。

### 6.2 另外三处候选价值

- **解释与帮助**：根据孩子刚才的回应，在已有帮助层级内换一种短而清楚的说法。
- **共同经历接续**：用真实的上次活动与作品组织邀请或回顾，不编造历史。
- **家长和外教摘要**：把具体证据整理成可读反馈与备课草稿，每条描述可追溯。

这些场景可以先采用模板，再比较模型是否带来明确增益。核心绘本文本、教学目标与活动规则由教研确定；模型输出遵循当前任务、语言范围和允许动作。

语音识别、语义理解与能力判定分别处理。模型服务不可用时，已有音频、任务分支与选择活动继续支撑完整单元。

### 6.3 样板比较什么

比较预设回应与模型辅助回应时，观察：孩子能否更容易被理解、是否更少需要成人解释、任务能否继续、帮助是否记录准确、反馈能否回溯，以及响应速度、稳定性和体验成本。采用与否依据这些结果，不依据生成文字的丰富程度。

## 7. 旅行册与家长证据如何共用一份经历

### 7.1 孩子的旅行页

显示野餐场景、孩子选过的物品、伙伴的具体回顾和允许保存的作品。孩子可以再次讲述或重读故事。没有录音也能留下完整旅行页。

### 7.2 家长的本次表现卡

> **今天完成：准备野餐。**  
> 参与：在伙伴引导下完成听读与装篮子活动。  
> 听懂：在三张食物图片中，听到名称后选出相应物品；本次没有额外语义示范。  
> 表达：在示范后尝试了一个短语，本次记为模仿表达。  
> 支持：部分步骤使用了重听；如成人协助未确认，明确显示未记录。  
> 下一步：换一次材料继续观察，生活延伸为可选。  
> 查看依据：具体活动、材料、回应和已提供帮助。

以上仅为格式示例，不是真实数据。家长报告由活动记录生成，无需先手工填表。只有存在可比历史证据时才描述变化；没有观察文字解码时不据听读完成认定独立阅读能力。

导师方案在同一证据基础上增加老师观察、解释与计划调整，避免家庭需要反复向新老师复述经历。

## 8. 权益页面如何衔接体验

- 免费样板包含完整故事结尾、相关任务、旅行页和本次反馈。
- 家庭订阅增加持续内容、路径安排和周期回顾，孩子可以继续自主体验。
- 导师周期包增加稳定导师的一对一交流、诊断和后续建议；家长侧清楚展示次数和服务边界。
- 家长在查看样板反馈、后续计划或主动预约时进入权益选择。
- 孩子进行中的故事不出现支付流程；伙伴关系、已有作品和基础记录不因购买等级改变。
- 大语言模型嵌入相应任务体验，暂不增加面向孩子的聊天次数购买入口。正式计费、服务数量与有效期需后续确认。

## 9. 结构进入页面设计前的检查

1. 各年龄组均有适龄版本，并能适配不同英语起点。
2. 无需识字可以理解主要操作，有可使用的重听、帮助与退出。
3. 从进入到收尾的主流程不依赖家长逐步讲解，试用时记录仍需协助的位置。
4. 沉默、语音未确认、任务困难、暂停后返回都有可继续的路径。
5. 旅行页、本次反馈与导师摘要引用同一组真实记录，支持条件可追溯。
6. 模型未启用或不可用时，仍能完成单元；有模型时能验证其具体增益。
7. 原创样板和外教服务能支撑实际展示的权益，价格与数量确认前不作确定承诺。

下一阶段以这些结构为依据，选择角色与视觉方向，再形成具体页面设计和可交互样板。
